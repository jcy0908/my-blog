색상 값을 한 파일에서만 바꾸면 사이트 전체가 따라 바뀌길 바라며 CSS 변수를 써봤는데, 단순한 치환 이상의 동작이 있다는 걸 오늘 알게 됐다. `--이름` 으로 선언하고 `var()` 로 읽는 이 문법은 Sass 변수와 달리 브라우저가 런타임에 계산한다.

## 선언과 스코프

CSS 변수는 `--primary-color: #1a73e8;` 처럼 두 개의 하이픈으로 시작하며, 선언된 선택자의 하위 요소에서만 상속되어 보인다. `:root` 에 선언하면 문서 전체에서 쓸 수 있고, 특정 컴포넌트 클래스 안에 선언하면 그 안에서만 값을 덮어쓸 수 있다.

```
:root {
  --primary-color: #1a73e8;
}

.card--danger {
  --primary-color: #d93025;
}

.card {
  border-color: var(--primary-color);
}
```

## 전처리기 변수와 다른 점

Sass 변수는 빌드 시점에 텍스트로 치환되고 끝이지만, CSS 변수는 살아있는 값이라 JavaScript로 `element.style.setProperty()` 를 호출하면 즉시 화면에 반영된다. 또한 캐스케이딩을 따르기 때문에 미디어 쿼리 안에서 같은 변수 이름의 값만 바꿔주면 반응형 테마 전환도 별도 클래스 없이 가능하다.

## 기본값과 폴백

`var()` 의 두 번째 인자로 폴백 값을 지정할 수 있어서, 변수가 아직 선언되지 않았거나 오타가 나도 레이아웃이 깨지지 않는다. `var(--gap, 16px)` 처럼 쓰면 `--gap` 이 없을 때 16px가 대신 적용된다.

CSS Custom Properties는 단순한 상수 저장소가 아니라 상속과 캐스케이딩을 따르는 살아있는 값이며, 이 특성 덕분에 다크 모드 전환이나 컴포넌트별 테마 오버라이드를 자바스크립트 없이도 CSS만으로 구현할 수 있다.
