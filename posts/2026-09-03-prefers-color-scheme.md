운영체제 설정을 다크 모드로 바꾸면 방문한 적도 없는 사이트가 알아서 어두운 배경으로 뜨는 경우가 있다. 자바스크립트 없이 CSS만으로 이런 반응이 가능하다는 걸 오늘 다시 확인했다.

## 미디어 쿼리로 감지하기

`prefers-color-scheme`은 사용자의 시스템 색상 모드를 읽는 미디어 쿼리다. `light`와 `dark` 두 값을 가지며, 값에 따라 다른 색상 변수를 적용할 수 있다.

```
:root {
  --bg: #ffffff;
  --text: #111111;
}
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #111111;
    --text: #eeeeee;
  }
}
body {
  background: var(--bg);
  color: var(--text);
}
```

## color-scheme으로 브라우저 기본 UI까지 맞추기

`color-scheme: light dark;`를 지정하면 스크롤바, 폼 요소 같은 브라우저 기본 UI도 현재 모드에 맞춰 자동으로 바뀐다. 색상 변수만 바꾸면 배경과 글자색은 맞아도 스크롤바만 밝게 남는 경우가 있는데, 이 속성이 그 어색함을 해결해준다.

## 사용자가 직접 고르게 하기

시스템 설정만 따르면 사이트 안에서 모드를 바꿀 수 없다. `html`에 `data-theme` 속성을 두고 버튼으로 값을 토글한 뒤, `[data-theme="dark"]` 선택자가 미디어 쿼리보다 우선하도록 CSS 순서를 정하면 시스템 설정과 사용자 선택을 함께 지원할 수 있다.

시스템 설정을 기본값으로 따르되 사용자가 직접 바꿀 수 있는 여지를 남겨두는 것이 다크 모드 구현의 핵심이다.
