Sass를 쓰면서 가장 그리웠던 문법이 중첩 선택자였는데, 이제는 브라우저가 이를 네이티브로 지원한다. 빌드 도구 없이도 `&`로 부모 선택자를 참조하며 규칙을 묶을 수 있다.

## 기본 중첩

CSS 규칙 블록 안에 다른 선택자를 그대로 넣으면 자동으로 조상 선택자와 결합된다. 자식 결합자는 생략해도 되고, `&`로 부모 자리를 명시할 수도 있다.

```css
.card {
  padding: 1rem;

  & h2 {
    margin: 0;
  }

  &:hover {
    box-shadow: 0 2px 8px #0002;
  }
}
```

## 왜 `&`가 중요한가

`&` 없이 가상 클래스나 속성을 바로 쓰면 자손 선택자로 해석될 위험이 있다. `&:hover`처럼 명시하면 복합 선택자가 되어 의도가 분명해지고, `&.active`처럼 클래스를 덧붙이는 패턴도 가능하다.

## 중첩 안의 미디어 쿼리

`@media`나 `@supports`도 선택자 블록 안에 그대로 중첩할 수 있어, 같은 컴포넌트의 반응형 규칙을 한곳에 모아둘 수 있다.

```css
.card {
  @media (width >= 768px) {
    padding: 2rem;
  }
}
```

Sass의 중첩이 빌드 시점에 평탄화되는 것과 달리, 네이티브 CSS 중첩은 브라우저가 런타임에 해석하므로 전처리기 없이도 컴포넌트 단위로 스타일을 응집시킬 수 있다. 다만 과하게 깊이 중첩하면 가독성과 선택자 우선순위가 동시에 복잡해지니, 2~3단계 안에서 쓰는 것이 좋다.
