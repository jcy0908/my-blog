지금까지 CSS 선택자는 항상 아래로만 향했다. `.card img`처럼 자식은 고를 수 있어도 "이미지를 가진 카드"처럼 부모를 조건부로 고르는 건 불가능해서 결국 JavaScript로 클래스를 붙이곤 했다. `:has()`는 이 방향을 뒤집어서 조건에 맞는 자손을 가진 요소 자체를 선택하게 해준다.

## :has()가 하는 일

`:has()`는 괄호 안 선택자에 매칭되는 요소가 하나라도 있으면 참이 되는 슈도클래스다. `article:has(img)`는 이미지가 들어있는 `article`만 고른다. 흔히 "부모 선택자"라고 부르지만 실제로는 형제나 자기 자신 이후 요소에도 쓸 수 있어서 더 일반적인 "관계형 선택자"에 가깝다.

## 코드로 보는 활용

```css
/* 이미지가 없는 카드에만 여백 스타일 적용 */
.card:not(:has(img)) {
  padding: 2rem;
}

/* 체크된 input 바로 다음 라벨 강조 */
input:checked + label {
  font-weight: bold;
}

/* 폼 유효성 실패 필드가 있으면 제출 버튼 흐리게 */
form:has(:invalid) button[type="submit"] {
  opacity: 0.5;
}
```

세 번째 예시처럼 폼 전체 상태를 자식 요소들의 상태로 판단할 수 있다는 점이 특히 유용하다.

## 주의할 점

`:has()`는 최신 브라우저에서는 대부분 지원되지만, 오래된 브라우저를 지원해야 한다면 여전히 fallback이 필요하다. 또 괄호 안 선택자 범위가 넓으면 브라우저가 매 렌더링마다 자손을 훑어야 해서 성능에 영향을 줄 수 있으므로, 검사 범위를 최대한 좁게 잡는 게 좋다.

> `:has()` 덕분에 "조건에 맞는 자손이 있을 때 부모 스타일을 바꾼다"는 로직을 JS 없이 CSS만으로 표현할 수 있게 됐다.

---

오늘은 `:has()` 관계형 슈도클래스로 부모나 형제 요소를 자손의 상태에 따라 스타일링하는 방법을 정리했다. 지금까지 클래스 토글로 처리하던 UI 상태 스타일 중 일부는 `:has()`로 옮겨서 JS 의존도를 줄여볼 수 있을 것 같다.
