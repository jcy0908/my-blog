`for...of`로 배열이나 Map을 순회하는 건 당연하게 써왔지만, 그 뒤에 어떤 규칙이 숨어 있는지는 제너레이터를 직접 써보기 전까지 몰랐다. 오늘은 멈췄다가 다시 시작하는 함수, 제너레이터를 들여다봤다.

## function*와 yield

`function*`로 선언한 함수는 호출해도 즉시 실행되지 않고 이터레이터 객체를 반환한다. `.next()`를 부를 때마다 `yield`를 만난 지점까지 실행되고 그 자리에서 멈춘다.

```js
function* range(start, end) {
  for (let i = start; i <= end; i++) {
    yield i;
  }
}

for (const n of range(1, 3)) {
  console.log(n); // 1 2 3
}
```

## 이터레이터 프로토콜과의 관계

`Symbol.iterator`를 직접 구현하려면 `next()`가 `{ value, done }`을 수동으로 관리해야 해서 번거롭다. 제너레이터는 이 상태 관리를 언어가 대신 맡아주는 문법적 설탕에 가깝다. 커스텀 클래스에 `[Symbol.iterator]`를 제너레이터로 달아주면 바로 `for...of`와 전개 연산자를 쓸 수 있다.

## 요약

제너레이터는 '멈췄다가 다시 시작하는 함수'라는 개념으로, 이터레이터 프로토콜을 손으로 구현하는 수고를 덜어준다. 무한 시퀀스나 지연 계산이 필요할 때 특히 유용하다.
