---
title: 포커스가 안쪽에 있어도 알려주는 CSS, :focus-within
date: 2026-11-10
tags: [CSS, 접근성]
---

검색창에 input과 버튼이 나란히 붙어 있는 박스를 만들다가, 포커스가 input에 가 있을 때 전체 박스에 테두리를 입히고 싶었다. `:focus`는 포커스를 받은 요소 자신에게만 적용되어서 부모 div는 아무 변화가 없었다. 여기서 `:focus-within`이라는 슈도클래스를 알게 됐다.

## :focus-within이 하는 일

`:focus-within`은 요소 자신이 포커스를 받았을 때뿐만 아니라, 자손 요소 중 하나라도 포커스를 받으면 매칭된다. input을 감싸는 부모에 이 슈도클래스를 걸어두면, 사용자가 탭으로 이동해 내부 input에 들어가는 순간 부모 전체가 스타일을 받을 수 있다.

```css
.search-box {
  border: 1px solid #ddd;
}

.search-box:focus-within {
  border-color: #3b82f6;
  box-shadow: 0 0 0 3px rgba(59, 130, 246, 0.2);
}
```

## :focus와의 차이

`:focus`는 딱 그 요소 하나만 보고, `:focus-within`은 자신을 포함한 하위 트리 전체를 본다. 폼 그룹이나 카드형 레이아웃처럼 여러 요소가 하나의 묶음으로 보여야 하는 곳에서 특히 유용하다.

키보드로 폼을 채워나가는 사용자에게 지금 어디에 있는지를 시각적으로 계속 알려주는 것도 접근성의 일부라는 걸 다시 느꼈다. 자바스크립트로 포커스 이벤트를 감지해 클래스를 토글하지 않아도, CSS 한 줄로 같은 효과를 낼 수 있다는 점이 특히 좋았다.
