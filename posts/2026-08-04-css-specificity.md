title: CSS 명시도는 어떻게 계산될까
date: 2026-08-04
tags: [CSS, 웹개발]
---

분명 나중에 작성한 CSS 규칙인데 적용이 안 될 때가 있다. 원인을 찾아보니 순서가 아니라 **명시도(specificity)** 문제였다. 오늘은 브라우저가 어떤 규칙을 우선 적용할지 정하는 기준을 정리해봤다.

## 명시도는 점수로 계산된다

브라우저는 선택자마다 (인라인 스타일, id, class/속성/가상클래스, 태그) 네 단계의 점수를 매기고, 높은 점수를 가진 규칙을 적용한다. `id` 선택자 하나가 `class` 선택자 여러 개보다 항상 우선한다.

```css
#header .nav { color: blue; }   /* id 1개, class 1개 */
.nav a { color: red; }          /* class 1개, 태그 1개 */
```

위 예시에서는 `id`가 포함된 첫 번째 규칙이 이긴다. 두 규칙의 순서를 바꿔도 결과는 같다.

## !important는 마지막 수단

`!important`를 붙이면 명시도 계산을 건너뛰고 최우선 적용되지만, 남용하면 나중에 오버라이드할 방법이 없어진다. 가능하면 선택자 구조를 정리해서 해결하는 게 낫다.

명시도를 이해하면 "왜 이 스타일이 안 먹히지"라는 디버깅 시간을 크게 줄일 수 있다. 선택자를 작성할 때부터 불필요하게 구체적으로 쓰지 않는 습관이 중요하다는 걸 다시 느꼈다.
