린트를 돌리는 걸 매번 깜빡하고 커밋해버린 적이 있다면, 그 과정을 사람이 아니라 Git에게 맡길 수 있다. **Git hooks**는 커밋이나 푸시 같은 특정 시점에 자동으로 실행되는 스크립트로, 별도 패키지 없이 Git 자체 기능이다.

## .git/hooks 안의 평범한 스크립트

새 저장소를 만들면 `.git/hooks/` 안에 `pre-commit.sample` 같은 예시 파일들이 이미 들어 있다. 확장자 `.sample`을 떼고 실행 권한만 주면 그대로 동작한다. 다만 `.git/` 폴더는 커밋 대상이 아니라서, 이 훅들은 클론해도 함께 복사되지 않는다. 팀 전체가 같은 훅을 쓰려면 husky 같은 도구로 훅 설치를 npm install 과정에 끼워 넣는다.

## 커밋을 막아보기

`pre-commit` 훅은 커밋이 만들어지기 직전에 실행되고, 스크립트가 0이 아닌 값으로 종료되면 커밋 자체가 취소된다.

```
#!/bin/sh
if git diff --cached | grep -q "console.log"; then
  echo "console.log를 지우고 다시 커밋하세요"
  exit 1
fi
```

## 어떤 시점들이 있나

`pre-commit` 외에도 커밋 메시지를 검사하는 `commit-msg`, 푸시 직전에 실행되는 `pre-push` 등 Git 생명주기의 여러 지점에 훅을 걸 수 있다.

결국 Git hooks는 "잊지 말고 검사하자"는 약속을 스크립트로 바꿔, 사람이 실수할 여지를 Git 레벨에서 없애버리는 장치다.
