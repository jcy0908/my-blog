---
title: 패딩 트릭 없이 비율 고정하기, CSS aspect-ratio
date: 2026-10-05
tags: [CSS, 레이아웃]
---

이미지나 영상 영역의 가로세로 비율을 고정하려고 `padding-bottom: 56.25%` 같은 트릭을 써본 적이 있을 것이다. `aspect-ratio` 속성은 이런 우회 없이 비율을 직접 선언하게 해준다.

## 너비만 알아도 높이가 정해진다

`aspect-ratio: 16 / 9`를 선언하면 너비가 정해지는 순간 높이가 자동으로 비율에 맞춰 계산된다. 반응형 레이아웃에서 너비는 퍼센트나 그리드로 유동적으로 바뀌어도, 높이는 늘 같은 비율을 유지한다.

```css
.thumbnail {
  width: 100%;
  aspect-ratio: 16 / 9;
  object-fit: cover;
}
```

## 이미지에도, 빈 박스에도

`img`나 `video`뿐 아니라 콘텐츠가 아직 없는 빈 `div`에도 적용할 수 있다. 이미지가 로드되기 전부터 자리를 미리 차지해두면, 로드 완료 시 레이아웃이 밀리는 현상(레이아웃 시프트)을 막을 수 있다.

## content가 비율을 넘어서면

내부 콘텐츠가 비율로 계산된 크기보다 커지면 `aspect-ratio`는 강제로 잘라내지 않고 요소가 늘어난다. 넘치는 내용을 확실히 비율 안에 가두려면 `overflow: hidden`을 함께 써야 한다.

## 요약

`aspect-ratio`는 패딩 트릭 없이 가로세로 비율을 선언적으로 고정하는 CSS 속성이다. 이미지의 레이아웃 시프트를 막는 데 특히 유용하며, 콘텐츠가 비율을 넘어설 때는 `overflow` 처리를 함께 고려해야 한다.
