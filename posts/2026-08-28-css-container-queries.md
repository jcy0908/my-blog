미디어 쿼리는 항상 뷰포트 너비를 기준으로 삼는다. 그런데 같은 카드 컴포넌트가 넓은 메인 영역에도, 좁은 사이드바에도 들어간다면 뷰포트만으로는 각 위치에 맞는 스타일을 줄 수 없다. 이 문제를 풀어주는 게 **컨테이너 쿼리**다.

## 컨테이너로 지정하기

먼저 기준이 될 부모 요소에 `container-type`을 선언해야 한다.

```css
.card-wrapper {
  container-type: inline-size;
  container-name: card;
}
```

`inline-size`는 가로 폭을 기준으로 삼겠다는 뜻이다.

## 컨테이너 쿼리 적용하기

이제 자식 요소는 뷰포트가 아니라 저 컨테이너의 크기를 기준으로 스타일을 바꿀 수 있다.

```css
@container card (min-width: 400px) {
  .card-title {
    font-size: 1.5rem;
  }
}
```

같은 `.card-title`이라도 좁은 컨테이너 안에서는 작게, 넓은 컨테이너 안에서는 크게 렌더링된다.

## 미디어 쿼리와의 차이

> 미디어 쿼리: "화면이 이 정도 넓은가?"
> 컨테이너 쿼리: "내가 들어있는 상자가 이 정도 넓은가?"

컴포넌트를 재사용 가능하게 설계할 때는 후자가 훨씬 자연스럽다.

정리하면, 컨테이너 쿼리는 컴포넌트 스스로 자기 자리의 크기를 인지하고 반응하게 만들어 준다. 디자인 시스템처럼 같은 컴포넌트를 여러 레이아웃에 재사용해야 하는 상황에서 특히 유용하다.
