SPA에서만 가능한 줄 알았던 부드러운 화면 전환을, 순수 브라우저 API만으로 구현할 수 있다는 사실을 오늘 알았다. 바로 View Transitions API다.

## 화면을 통째로 캡처해서 바꿔치기한다

`document.startViewTransition()`을 호출하면 브라우저는 현재 화면을 스크린샷처럼 캡처해두고, 콜백 안에서 DOM을 원하는 상태로 바꾼 뒤 새 화면을 다시 캡처한다. 그리고 두 이미지를 크로스페이드로 자연스럽게 섞어 보여준다. 개발자는 DOM만 바꾸면 되고 전환 애니메이션은 브라우저가 알아서 만들어준다.

## 코드 한 줄로 시작하기

```js
if (document.startViewTransition) {
  document.startViewTransition(() => {
    updateDOM();
  });
} else {
  updateDOM();
}
```

지원하지 않는 브라우저를 위한 분기만 넣어주면 끝이다. 특정 요소만 따로 전환시키고 싶다면 CSS의 `view-transition-name` 속성으로 요소를 지정하면 된다.

## 아직은 점진적 향상 대상

크로미움 계열은 지원이 빠르지만 사파리, 파이어폭스는 아직 따라오는 중이라 필수 기능이 아니라 있으면 좋은 향상 요소로 다뤄야 한다.

이 API를 쓰면 복잡한 트랜지션 라이브러리 없이도 상태 변화 전후를 부드럽게 이어 붙일 수 있고, 핵심은 지원 여부를 분기 처리해 점진적 향상으로 접근하는 것이다.
