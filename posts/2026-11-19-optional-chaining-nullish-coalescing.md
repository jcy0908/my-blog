`user && user.address && user.address.city` 처럼 중간 단계가 비어있을까봐 매번 체크하던 코드를, 오늘 옵셔널 체이닝(`?.`)과 null 병합(`??`)으로 훨씬 짧게 쓸 수 있다는 걸 다시 정리했다.

## 체이닝 중간이 비어도 안전하게

`?.`은 앞쪽 값이 `null`이나 `undefined`면 거기서 평가를 멈추고 `undefined`를 돌려준다. 에러를 던지지 않는다는 점이 핵심이다.

```js
const city = user?.address?.city;
const name = user?.getName?.();
const first = list?.[0];
```

함수 호출과 배열 인덱싱에도 똑같이 쓸 수 있어서, 존재할 수도 없을 수도 있는 메서드나 값을 다룰 때 특히 편하다.

## ||가 아니라 ??를 써야 하는 이유

기본값을 줄 때 `||`를 쓰면 `0`이나 `''`, `false`처럼 falsy하지만 유효한 값도 기본값으로 덮어써 버린다. `??`는 오직 `null`과 `undefined`일 때만 오른쪽 값을 쓴다.

```js
const count = input ?? 10;   // input이 0이어도 0 유지
```

## 함께 쓸 때 주의할 점

`?.`과 `??`를 섞어 쓸 때는 `(a?.b) ?? c`처럼 괄호로 우선순위를 명확히 해주는 게 안전하다. 둘 다 "값이 있는지 모를 때"를 다루는 문법이지만, 하나는 접근을, 하나는 기본값을 책임진다는 역할 차이를 기억해두면 헷갈리지 않는다.
