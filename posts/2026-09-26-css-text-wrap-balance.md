카드 제목이 두 줄로 넘어갈 때 마지막 줄에 단어 하나만 덩그러니 남는 걸 고치려고 `<br>`을 수동으로 넣곤 했는데, `text-wrap: balance` 속성 하나로 브라우저가 알아서 균형 잡힌 줄바꿈을 해준다는 걸 알게 됐다.

## text-wrap: balance란

브라우저가 텍스트를 여러 줄로 나눌 때, 각 줄의 길이가 최대한 비슷해지도록 줄바꿈 지점을 다시 계산해주는 속성이다. 기본값인 `wrap`은 그냥 줄 끝까지 채우다 넘치면 다음 줄로 넘기지만, `balance`는 전체 줄 수를 유지하면서 줄 사이 길이 편차를 줄인다.

## 적용 대상과 제한

제목이나 인용문처럼 줄 수가 적은 블록 요소에 쓰는 게 좋다. 브라우저가 여러 줄바꿈 조합을 계산해봐야 하므로 비용이 들고, 그래서 대부분의 구현체는 일정 줄 수(보통 6줄) 이하에서만 적용하고 그 이상은 조용히 `wrap`으로 되돌아간다. 본문처럼 긴 문단에는 적합하지 않다.

```css
h2.card-title {
  text-wrap: balance;
}

blockquote {
  text-wrap: balance;
}
```

## 지원 확인은 필수

아직 모든 브라우저가 지원하는 건 아니라서, 지원하지 않는 브라우저에서는 값이 무시되고 기본 줄바꿈으로 자연스럽게 폴백된다. 별도의 `@supports` 분기 없이도 안전하게 추가할 수 있는 점진적 향상(progressive enhancement) 속성이다.

`text-wrap: balance`는 제목처럼 줄 수가 적은 텍스트의 줄바꿈 균형을 브라우저가 알아서 맞춰주는 CSS 속성으로, 미지원 브라우저에서도 그냥 무시되니 부담 없이 추가할 수 있다는 점이 오늘 배운 핵심이다.
