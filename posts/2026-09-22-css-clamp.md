오늘은 반응형 타이포그래피를 다루면서 `clamp()` 함수를 제대로 써봤다. 화면 크기마다 `font-size`를 미디어 쿼리로 일일이 나눠 쓰던 습관이 있었는데, `clamp()` 하나면 최소값과 최대값 사이를 뷰포트 크기에 맞춰 부드럽게 늘렸다 줄였다 할 수 있다는 걸 알고 나니 코드가 훨씬 간결해졌다.

## clamp()의 구조

`clamp(최솟값, 선호값, 최댓값)` 세 개의 인자를 받는다. 브라우저는 가운데 선호값을 우선 적용하되, 그 값이 최솟값보다 작아지면 최솟값으로, 최댓값보다 커지면 최댓값으로 고정한다. 선호값 자리에 `vw` 단위를 섞어 쓰면 뷰포트 너비에 비례해 자연스럽게 커지는 값을 만들 수 있다.

## 실전 예시

```css
h1 {
  font-size: clamp(1.5rem, 4vw + 1rem, 3rem);
}
```

이렇게 쓰면 작은 화면에서는 1.5rem 아래로 내려가지 않고, 큰 화면에서는 3rem을 넘지 않으면서 그 사이를 부드럽게 오간다. 미디어 쿼리 여러 줄을 줄 하나로 대체한 셈이다.

## 주의할 점

`vw` 단위만 넣으면 사용자가 브라우저 확대/축소를 해도 글자 크기가 그대로인 경우가 있어 접근성에 좋지 않다. `rem`을 함께 섞어 쓰면 확대 배율을 반영하면서도 화면 크기에 반응하는 값을 만들 수 있다.

`clamp()`는 최소·선호·최대 세 값만으로 미디어 쿼리 없이 반응형 크기를 만드는 CSS 함수다. `vw`와 `rem`을 함께 섞어 쓰면 화면 크기에는 반응하면서도 브라우저 확대/축소 접근성은 해치지 않는 값을 만들 수 있다는 점이 오늘의 핵심이다.
