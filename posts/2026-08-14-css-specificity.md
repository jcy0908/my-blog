버튼 색 하나를 바꾸려고 CSS를 수정했는데 반영되지 않아서 `!important`를 붙여본 적이 있다면, 대부분 원인은 명시도(specificity)다. 브라우저는 여러 선택자가 같은 요소를 가리킬 때 우선순위를 계산해서 어떤 스타일을 적용할지 정한다.

## 명시도는 어떻게 계산되나

명시도는 보통 (인라인, id, class/속성/가상클래스, 태그) 네 자리로 표현한다.

- 인라인 스타일: 1000
- id 선택자: 100
- class, 속성, 가상클래스: 10
- 태그, 가상요소: 1

예를 들어 `#nav .active`는 id 1개 class 1개라 `.active` 하나짜리 선택자보다 항상 우선한다.

## 코드로 보는 우선순위 다툼

```css
.btn { color: blue; }
#submit.btn { color: red; }
```

두 규칙이 같은 요소에 적용되면 id가 포함된 아래쪽 규칙이 이긴다. 코드 작성 순서보다 명시도가 먼저 비교된다.

## !important와 상속을 조심하기

`!important`는 명시도 계산을 무시하고 최우선으로 적용되지만, 남발하면 이후 어떤 선택자로도 덮어쓰기 어려워져서 유지보수가 힘들어진다. 정말 필요한 경우가 아니라면 선택자를 더 구체적으로 쓰는 쪽이 낫다.

> 명시도가 같다면 마지막에 선언된 규칙이 이긴다.
