title: 반복되는 선택자를 묶어주는 :is()와 :where()
date: 2026-10-04

---

`header nav a, header aside a, header footer a` 같은 선택자를 쓰다 보면 어느 순간 중복이 눈에 밟힌다. `:is()`와 `:where()`는 이런 반복을 묶어서 짧게 쓰게 해주는 CSS 함수다.

## 괄호 안에 여러 선택자를 한 번에

`:is()`는 괄호 안에 쉼표로 선택자 목록을 받아, 그중 하나라도 맞으면 매칭된다. 위 예시는 `header :is(nav, aside, footer) a`로 줄어든다. 목록 안에 잘못된 선택자가 하나 섞여 있어도 나머지는 그대로 동작한다는 점도 실용적이다.

## 유일한 차이는 명시도(specificity)

`:is()`는 괄호 안에서 가장 명시도가 높은 선택자의 값을 그대로 가져간다. 반면 `:where()`는 명시도를 항상 0으로 취급한다. 그래서 나중에 다른 규칙으로 쉽게 덮어쓰고 싶은 기본 스타일(리셋, 컴포넌트 기본값)에는 `:where()`가 유리하다.

```css
:where(h1, h2, h3) {
  margin: 0;
}
```

## 요약

`:is()`와 `:where()`는 복잡한 선택자를 짧게 묶어 가독성을 높여주고, 둘 중 어떤 걸 쓰느냐로 명시도 전략까지 조절할 수 있다. 기본값을 깔아두는 코드라면 `:where()`를, 명시도가 필요한 일반 선택자라면 `:is()`를 쓰면 된다.
