목록 아이템 하나하나에 클릭 이벤트를 다는 대신, 부모 요소 하나에만 리스너를 달아도 똑같이 동작한다는 걸 다시 확인했다. 이걸 이벤트 위임(event delegation)이라고 부른다.

## 이벤트 버블링이 핵심

클릭 같은 이벤트는 실제로 이벤트가 발생한 요소에서 시작해 부모 방향으로 계속 전파된다. 이 특성 덕분에 자식 요소 개수와 상관없이 부모에 리스너 하나만 달아도 자식에서 일어난 이벤트를 감지할 수 있다.

## event.target으로 실제 클릭 대상 찾기

부모에서 이벤트를 받으면 `event.target`이 실제로 클릭된 요소를 가리킨다. 여기서 원하는 요소인지 `closest()`로 확인하면 어떤 자식이 클릭됐는지 정확히 알 수 있다.

```js
list.addEventListener('click', (e) => {
  const item = e.target.closest('li');
  if (item) console.log('clicked:', item.textContent);
});
```

## 언제 유용한가

목록처럼 아이템이 동적으로 추가·삭제되는 경우 특히 유용하다. 아이템마다 리스너를 새로 붙이거나 제거할 필요 없이, 부모의 리스너 하나가 항상 동작하기 때문이다. 리스너 개수가 줄어드니 메모리 사용량도 줄어든다.

## 정리

이벤트 위임은 자식 요소마다 리스너를 다는 대신 부모 하나에만 리스너를 달고 `event.target`으로 실제 대상을 판별하는 패턴이다. 동적으로 늘어나는 목록을 다룰 때 특히 유용하고, 리스너 관리 부담도 크게 줄어든다.
