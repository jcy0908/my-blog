# 사칙연산 계산기 — 계획 문서 (spec)

## 1. 개요

더하기/빼기/곱하기/나누기를 지원하는 간단한 계산기. 퍼센트, 백스페이스, 연속 연산, 0으로 나누기 예외 처리를 포함한다.

## 2. 파일 구조

`/apps/calculator/` 폴더 내부에 아래 파일만 생성한다 (자체 완결, 외부 폴더 참조 없음).

- `index.html` — 디스플레이(수식/결과) + 4x5 키패드 마크업, 사용법 안내 문구 포함
- `style.css` — 라이트/다크 CSS 변수(자체 팔레트, `prefers-color-scheme` + `data-theme` 수동 토글), 모바일 반응형
- `script.js` — 계산 상태 관리(현재값/이전값/연산자), 클릭·키보드 입력 처리, 연속 연산, 0으로 나누기 시 "오류" 표시, 다크모드 토글 + `localStorage` 저장

## 3. 핵심 로직

- 상태: `currentValue`(문자열), `previousValue`, `pendingOp`, `overwrite` 플래그로 구성.
- 연산자 선택 시 이전 연산이 대기 중이면 먼저 계산(연속 연산 지원).
- `0 ÷ 0` 등 `NaN`/`Infinite` 결과는 "오류"로 표시하고 다음 입력 전까지 계산 차단.
- 키보드: 숫자, `+ - * /`, `Enter`/`=`, `Backspace`, `Escape`, `%` 지원.

## 4. UI/디자인

- 자체 CSS 변수로 라이트/다크 테마 관리(2048/pixel-art와 동일한 패턴).
- 모바일 퍼스트: `max-width: 380px` 컨테이너, 4열 그리드 키패드, 작은 화면에서 폰트/패딩 축소.
- 사용법 안내는 화면 하단 footer 문구로 대체(README 없음).

## 5. 외부 의존성

없음. 순수 HTML/CSS/JavaScript(ES 모듈)만 사용.

## 6. 검증 결과

로컬 서버로 브라우저 테스트 완료: `7 × 6 = 42`, `0 ÷ 0` → "오류" 표시(크래시 없음), 다크모드 토글 정상, 모바일 뷰포트(375×812) 레이아웃 정상.
